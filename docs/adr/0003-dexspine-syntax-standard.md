# ADR 0003: DEX838 `dex(scope, @context)["subject"]` Wire Syntax Standard

- **Status**: accepted
- **Date**: 2026-07-27

## Context
Historical DEX specifications contained 6 different bracket syntax delimiters (`dex()`, `dex[]`, `dex{}`, `dex<>`, `dex*`, `dex:`). Meanwhile, DexSpine introduced DEX838 (`dex(scope, @context)["subject"]`) as a unified single-line wire syntax for deterministic LLM extractions and multi-agent IPC across DexCLI and ADE.

## Decision
We decide that **DEX838 `dex(scope, @context)["subject"]`** is the standard primary wire format and parser contract for agent instructions. Legacy delimiters `dex()` (softcode / intent) and `dex[]` (hardcode / implementation) are preserved as semantic qualifiers within DEX838 subject blocks.

## Consequences
- Single deterministic parser target for DexCLI prompt processing and ADE Tauri IPC bridges.
- Maintains human readability and legacy prompt compatibility while removing parsing ambiguity.
- All MVE output files generated by agent operations will standardize on `va.md` (values), `hu.md` (human insight), and `llm.md` (agent patterns).

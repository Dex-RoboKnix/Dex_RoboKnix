# DexFolio content is generated via DexSpine/DEX838, not authored ad hoc

A folio's nodes are populated by pointing DexFolio at a project folder or repo, which runs DexSpine via DEX838 over that source material to complete the nodes. This was a real choice: folio content could instead have been manually authored (Obsidian-style, entirely by hand) or generated by an unstructured LLM summarization pass. Routing generation through DexSpine/DEX838 ties DexFolio's core content pipeline to DexRoboKnix's existing deterministic-extraction standard rather than treating DexFolio as a general-purpose notes app with its own separate content model. Decided 2026-08-06 during a grilling session; no implementation exists yet.
